# BMI Calculator API

A REST API built using FastAPI that calculates Body Mass Index (BMI) and provides health recommendations.

## Features
- FastAPI
- POST API
- JSON Request & Response
- BMI Calculation
- Healthy Weight Range
- Diet Suggestions
- Exercise Recommendations
- Motivation Quotes

## Technologies
- Python
- FastAPI
- Uvicorn
- Pydantic
- Postman

## Run

```bash
uvicorn bmicalculator:app --reload
